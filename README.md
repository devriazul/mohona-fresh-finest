# mohona-fresh-finest

Demo landing page and storefront for **MOHONA — Fresh & Finest**: fresh fish, live crab, prawns, lobster and desi meat from Santoshpur, Salt Lake and Siliguri.

- Real product photos, animated hero, category tiles, deal-of-the-day countdown
- Product catalogue with search, filters, sorting, weight picker and quick view (from the MOHONA price list)
- Cart drawer and 3-step checkout with **Razorpay** (demo) and **Cash on Delivery** with OTP check
- Delivery slots and branch choice, with the Sunday-only rule for mutton

Live demo: https://devriazul.github.io/mohona-fresh-finest/
